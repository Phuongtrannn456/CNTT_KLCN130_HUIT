# Demo Script (10-15 Minutes)

1. **Giới thiệu nền tảng & Đăng nhập (1m)**
   - Teacher Login (MetaMask hoặc Password).
   - Mở màn hình Quản lý Challenge.

2. **Teacher tạo Challenge (2m)**
   - Nhập thông tin, tạo Challenge Web3.

3. **Student Đăng nhập & AI Matching (2m)**
   - Mở tab ẩn danh, Student Login bằng MetaMask.
   - Thể hiện tính năng "AI Khuyên dùng" (Dựa trên lịch sử/khối lớp).
   - Join Challenge vừa tạo.

4. **Nộp bài & AI Analysis (2m)**
   - Student Submit bài.
   - Chuyển sang màn hình Teacher, bấm "Phân tích AI". Hiển thị nhận xét gợi ý.

5. **Chốt điểm & Achievement (2m)**
   - Teacher điền điểm, đánh dấu FINAL.
   - Student check tab "Thành tựu" -> Xuất hiện Achievement.

6. **Web3 Claim (2m)**
   - Student bấm "Nhận Web3 Credential".
   - Popup MetaMask ký xác nhận. (Giải thích: Không tốn phí, hệ thống trả Gas).
   - Báo thành công (TxHash).

7. **Public Verification (2m)**
   - Mở Link Xác minh (Public, không cần đăng nhập).
   - Check Hash Match (Xanh), Wallet Ownership Match (Xanh).
   - So sánh dữ liệu không có thông tin PII.

8. **Revoke (1m)**
   - Teacher bấm Revoke.
   - F5 lại trang Public Verify -> Báo Lỗi/Chứng nhận đã bị Hủy bỏ (Verified = false).
