# Web3Vault

Web3Vault la kho tri thuc noi bo cho he thong Web3 + AI Competition Platform.

Muc tieu:
- Luu workflow, rule nghiep vu, quyet dinh ky thuat va loi da fix.
- Giup agent/doc/dev khong lap lai loi cu.
- Giu tri thuc dung voi ket qua da duoc nguoi dung xac nhan.

Quy tac ghi chep:
- Chi ghi "da fix" khi nguoi dung xac nhan da chay duoc, hoac co bang chung kiem tra ro rang.
- Neu task thay doi ket luan cu, cap nhat note cu thay vi tao note mau thuan.
- Khong luu secret, token, private key, mnemonic, API key.
- Moi note nen co ngay, boi canh, file lien quan, cach xu ly va bai hoc.

Thu muc chinh:
- `00_Inbox`: noi ghi nhanh thong tin chua phan loai.
- `01_Workflows`: luong nghiep vu va user journey.
- `02_Security`: auth, role, permission, MetaMask, JWT.
- `03_Errors`: loi da gap, nguyen nhan, cach fix.
- `04_Playbooks`: quy trinh thao tac lap lai.
- `05_Domain`: glossary va rule domain.
- `06_Architecture`: kien truc he thong va module boundary.
- `07_APIs`: route, contract API, request/response.
- `08_Database`: MongoDB schema, index, migration note.
- `09_Blockchain`: smart contract, network, on-chain rule.
- `10_AI_ML`: matching, scoring, feedback, ML service.
- `11_UI_UX`: UI flow va pattern man hinh.
- `12_Decisions`: ADR/quyet dinh thiet ke.
- `13_Task_Logs`: nhat ky task da lam.
- `14_References`: link/tom tat tai lieu chinh thong.
- `_templates`: mau note dung chung.
